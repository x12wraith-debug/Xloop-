# Xloop share - تطبيق مشاركة الملفات السريع

تطبيق أندرويد مجاني وخفيف لمشاركة الملفات والتطبيقات بسرعة فائقة عبر تقنية Wi-Fi Direct بدون إنترنت وبدون إعلانات مزعجة.

**Xloop share** is a free, ad-free Android application for sharing files and apps via Wi-Fi Direct without an internet connection.

* **[اضغط هنا للتحميل المباشر - Download Xloop share APK](https://x12wraith-debug.github.io/Xloop-/)**

## ✨ المميزات الرئيسية (Features)
* **بدون إنترنت أو إعلانات:** نقل سريع ومجاني تمامًا بدون استهلاك بيانات الهاتف.
* **مشاركة جماعية (Group Sharing):** إرسال الملفات لأكثر من جهاز في نفس الوقت.
* **الربط مع الكمبيوتر:** مشاركة الملفات بسهولة مع أجهزة الكمبيوتر.
* **واجهة بسيطة:** تصميم خفيف وسهل الاستخدام للجميع.
